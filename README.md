# Simulated Windows Terminal — Free Online Tool

**Simulated Windows Terminal.** Practice the Windows console with zero risk: a virtual filesystem, 30+ real CMD commands, PowerShell aliases and 5 guided lessons with self-assessment. 100% in your browser. No sign-up, no ads, 100% client-side.

🌐 **Demo en vivo / Live demo:** [miguelacm.es/tools/windows-terminal](https://miguelacm.es/tools/windows-terminal)

## ✨ Features

- **Real commands:** dir, cd, mkdir, rd /s, type, echo >, copy, move, ren, del with wildcards, tree, ipconfig, ping and more on a virtual filesystem.
- **Guided lessons:** 5 self-assessed lessons with hints: navigation, files, organizing, system and network, and PowerShell.
- **100% safe:** Everything is simulated in memory. Nothing touches your real computer.

## 🚀 Quick start

```bash
git clone https://github.com/m-a-c-m/WindowsTerminal.git
cd WindowsTerminal
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Environment variables (optional)

```env
NEXT_PUBLIC_SITE_URL=https://miguelacm.es/tools/windows-terminal
NEXT_PUBLIC_EMBED_URL=https://miguelacm.es/embed/windows-terminal
```
